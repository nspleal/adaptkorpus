# Nomenclatura do pacote Adaptkorpus

Esta edição padroniza a marca em metadados, lançadores, comentários e cópias de documentação incluídas na distribuição.

Os títulos e identificadores de documentos externos citados neste pacote foram normalizados editorialmente. Não são garantia de caminho físico existente nem transcrição literal do nome do documento original. Para localizar uma fonte, conferir seu assunto, data e conteúdo no inventário canônico. Os documentos externos e o histórico Git não foram reescritos por esta edição.

Os scripts de importação recebem o caminho real da fonte como argumento; exemplos de nomes não determinam onde o arquivo está. A URL do repositório deve ser obtida no acesso autorizado, e os serviços externos permanecem configurados pelo ambiente. Domínios mencionados em planejamento não significam domínio registrado ou configurado.

Os arquivos SQL históricos tiveram somente comentários de marca padronizados; o SQL executável é o mesmo. Não reaplicar migrações já executadas por causa desta alteração editorial.

Os identificadores curtos de persistência existentes são preservados para manter acesso aos dados locais. A ausência do nome anterior no conteúdo da distribuição não afirma ausência em histórico Git, cadastros remotos ou arquivos externos à distribuição.
